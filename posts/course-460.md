## 学习笔记

这篇笔记记录了我在学习《Sourcetree 可视化 Git》过程中的核心收获。Atlassian 的讲解由浅入深，把 工具链 领域的知识脉络梳理得非常清晰，我在 Git 方向上建立了更完整的知识框架。

### 印象最深的收获

1. 理论讲解与实战案例结合，知识不悬浮在概念层面；
2. 章节末的练习设计很有梯度，能即时检验掌握程度；
3. 对常见误区和易错点有专门强调，省去了自己踩坑的时间。

### 实践记录

学完每章后，我都把示例代码亲手敲了一遍，并在此基础上做了自己的变体练习。遇到卡壳时回到原文对照思路，比直接搜答案印象深得多。整个学习过程约持续 11 周，每天保持固定的学习时长，最终完成了全部 工具链 / Git 章节。

### 沉淀与反思

回顾这段学习经历，最重要的不是记住了多少 API，而是建立起了 工具链 的思维模型：遇到问题先定位概念，再查文档、看源码，最后动手验证。这份思维方式的转变，比课程本身的知识点更值钱。
